# Queued
Hub para pessoas que querem encontrar companhia para jogar

O Queued é um projeto de website desenvolvido como parte de um projeto acadêmico de qualidade de software e banco de dados.

---

O projeto tem como objetivo desenvolver uma rede social voltada para o público gamer, permitindo que jogadores se encontrem e se conectem com pessoas que possuem interesses e estilos de jogo semelhantes, facilitando a formação de equipes para seus jogos favoritos.
Atualmente, os jogadores utilizam os próprios sistemas de busca e formação de partidas disponíveis nos jogos para encontrar outros participantes. Entretando, esse processo é baseado principalmente na aleatoriedade, o que pode resultar na formação de equipes com experiência, objetivos e estilo de jogo diferentes. Como alternativa, muitos jogadores recorrem a comunidades e redes sociais externas, como fóruns, servidores e grupos de mensagens, para encontrar pessoas compatíveis e montar suas próprias equipes.
Diante desse cenário, a proposta do projeto é centralizar esse processo em uma plataforma específica para gamers. Nela, os usuários poderão criar perfis personalizados contendo seus jogos favoritos, preferências, interesses, habilidades e conquistas obtidas ao longo de sua experiência como jogador.
A plataforma também contará com uma área de busca e filtros que permitirá localizar outros jogadores de acordo com diferentes características, como jogo, nível de experiência, estilo de jogo e interesses em comum.
Dessa forma, os usuários poderão encontrar pessoas com maior compatibilidade e formas suas próprias equipes, criando uma experiência mais organizada e eficiente para a construção do seu dream team.
